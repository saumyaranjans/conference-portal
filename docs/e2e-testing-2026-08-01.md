## 2. Pathway A — full editorial tree (walked on fresh papers, all verified via DB)

1. **Convener assigns a Track Editor** (OPS-701 → New Editor)
   - Email (token Agree/Reject) **and** in-app notification created.
   - Track Editor **accepted** from the dashboard "Papers awaiting your acceptance" panel → `editor_accepted_at` set.
   - Acting in-app **nullifies the emailed token** (fixed: `respondToPaperAssignment` clears `editor_assignment_token`).
2. **Track Editor route = "Evaluate myself"** → decision form:
   - **Accept** (OPS-701) → `accepted`; author letter advises **registration** (Pathway A).
   - **Minor revision** (OPS-702) → `revisions_requested` (form stays open) → **Reject** → `rejected`. Revision/Reject letters carry **no** registration line.
3. **Track Editor route = "Send it out for review"** (OPS-703):
   - Reviewer 1 **declined** (reason captured, no role granted).
   - Reviewer 2 **accepted** (author+reviewer roles granted on accept) → **submitted a review** (single-blind, Avg 4.3, Accept).
   - Track Editor recorded **Accept** based on the review → `accepted`.
4. **Revision versioning** (OPS-704): author resubmitted after a revision request → **Version 2 (Revision 1)** label shown across dashboards (continues V3 = Revision 2 … until accepted).

## 3. Roles & invitations — rules implemented and verified

- **A role is granted only on ACCEPTANCE, never at invite/send; a reject grants nothing.** Fixed the premature grants in `sendReviewerInvite`, `addTrackChair`, `prepareTrackEditorInvite`, `reassignTrackEditor`; grants now live in the accept actions (`agreeReviewAssignment`, `respondToAssignment`, `acceptReviewerInvite`, `acceptTrackChairInvite`, `acceptTrackEditorInvite`, `agreePaperAssignment`).
- **Every reviewer / track editor also holds `author`** → at least two dashboards. Default role for any signup = `author`.
- **Two channels** for a signed-up invitee: **email + notification bell**; accept/reject from either. **Acting on one nullifies the other** (shared one-time token cleared on first action) — verified for both reviewer (`/review-invite/[token]`) and track editor (`/chair-invite/[token]`).
- **Landing rule:** for reviewer & track editor, **Accept → /login**, **Reject → home**.
- A **new invitation after a rejection** can still grant access (each invitation is its own token/assignment).
- **Caps:** max **10** review assignments per reviewer (declines don't count); max **2** tracks per track editor.
- **Regression found & fixed:** existing-account chair accept (`acceptTrackChairInvite`) wasn't granting the editor role after the role-on-accept refactor → "You do not have access to that area"; now grants author+editor on accept.

## 4. Pathway B — full-paper (manuscript) submission

- Abstract stage identical to Pathway A; Pathway B **activates on abstract acceptance** (`abstract_accepted` → `stage=full_paper`).
- **Track Editor sets the full-paper deadline** when accepting the abstract — validated **≤ the conference-wide `full_paper_deadline`** (seeded 2026-10-15) and in the future.
- **Acceptance email** (Pathway B) carries the **deadline + author-guidelines link** ("full-paper upload now available on your dashboard"). Letter stays the *abstract* letter until the full paper is submitted.
- **Two packaging options** (author picks one):
  - **Option A — separated / blind-ready:** Title Page*, anonymised Manuscript* (no author names, no tables/figures), Figures, Tables, Appendices, Supplementary, Others.
  - **Option B — combined:** Title Page*, Manuscript (figures/tables/appendices included)*, Supplementary, Others.
  - `*` = required. Multi-file slots take several files. (`submission_files` table.) Verified with dummy uploads on OPS-711 (A) and OPS-712 (B).
- **Publishing outlet selection** (checklist of the 4 outlets: GJFSM, IJGBC, Book Series, Conference Proceeding) — **at least one required**, gates submit.
- **Declaration re-affirmed on behalf of all authors** at the manuscript stage (all required to submit). Abstract **DETAILS editor hidden** at this stage (no re-entry needed).
- Full-paper submission gated on: required files + ≥1 outlet + all declarations + within deadline.
